# DoraCade

DoraCade is a 2D arcade game collection built in C using raylib, combining three unique mini-games into one Doraemon-inspired gaming experience. Players can explore different gameplay styles, challenge their skills, collect points, and aim for high scores.

🛩️ DoraRush — A fast-paced endless flying game where players control Doraemon, avoid incoming pipes, collect coins, and survive for as long as possible.

👻 DoraMan — A classic maze-based game where players navigate through a maze, collect pellets, avoid ghosts, and try to achieve the highest score.

🚀 DoraInvaders — An arcade-style shooting game where players defend themselves against waves of enemies, shoot targets, survive attacks, and earn points.

DoraCade brings these three different experiences together through a unified menu, sound effects, music, scoring systems, textures, and game-state management. The project was developed as a practical C programming project while focusing on modular code organization, game logic, collision detection, input handling, and a portable Windows release.
